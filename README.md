# Country Game

A country trivia game with social features. Guess countries based on clues, track your stats, and compete with friends.

## Features

- Interactive country guessing gameplay
- User accounts with profile management
- Social feed with likes and follows
- Search and discover other players
- Admin panel for content management

## Tech Stack

- **Frontend:** React 18, Redux Toolkit, React Router, Bootstrap
- **Backend:** [Node.js API](https://github.com/isaac-levine/country-game-node-server) with Express and MongoDB

## Getting Started

```bash
npm install
npm start
```

Requires the [backend server](https://github.com/isaac-levine/country-game-node-server) to be running.
